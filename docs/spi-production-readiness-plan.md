# SPI beta readiness

SPI is mandatory for the first release. Follow [beta scope](beta-scope.md),
[installation/recovery](install-and-recovery.md), [current state](implementation-status.md)
and [build/packaging](build-and-release.md).

Retain metadata-aware SPI identity/geometry/readback and recovery protections.
Reuse recorded SPI operation and recovery. The beta requires three cold plus
three warm applicable observations in total, including the final manual profile;
run only gaps. Completing automatic guest management, a managed ten-plus-ten
boot campaign and another soak are not prerequisites.

[Original managed production plan](archive/pre-beta-20261114/spi-production-readiness-plan.md)
is historical. The pause receipt preserves physical state, but its managed
resume checklist does not override this scope.

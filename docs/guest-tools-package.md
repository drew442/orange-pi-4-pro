# Guest tools availability

Use the complete authenticated `/usr/lib/a733-tools` belonging to the installed
immutable root. Manual operations share account, storage, admission, lifecycle,
checkpoint and host-maintenance dependencies; do not stage only one script or
mix old and new trees. The manual profile retains those dependencies while
disabling automatic managed dispatch.

[Manual guide](manual-guest-guide.md) contains current commands;
[build and release](build-and-release.md) constructs and packages a matching tree.
The original private recovery SD can carry older tools; use its documented
recovery procedure rather than pretending a current source checkout installed them.
